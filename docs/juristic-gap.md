## 7. Five findings that change estimates or order

1. **Co-owner and transfer billing are wrong today** (J1.1, `billing-cycles.service.ts:303-323,539-544`): each co-owner is billed the full common fee and mid-period ownership changes bill both parties in full. J1.1 must start with failing golden cases (60/40 co-owners, transfer on 15 Mar) before any new basis — and the existing `condo-common-fee-by-ratio` golden stays green.
2. **JR is much smaller than estimated**: invoices / receipts / payments are already scoped by billed party and community / service / access by `unit:` scope; only `SubjectService.resident` (add ownership units + derived roles), a `unit_resident` invitation kind, `units/{id}/usage`, and the 13 lease-keyed paths need work. JA does **not** need an RLS helper for it.
3. **Frequencies touch a unique key**: `ops.billing_cycle` is unique per (property, period_key) and (property, period_start); quarterly / annual juristic cycles next to monthly lease cycles in one property need `frequency` in both keys and frequency-aware period functions in `smart-readings/cutoff.ts` — the sweep also skips ownership-only properties. Plan J1.1 as two slices (frequency + sweep, then budgets / resolutions / register).
4. **Pack names that do not match the code**: `charge_basis` → `ops.rate_plan_version.basis` (`ops.rate_basis`); `ops.payment.transaction_ref` → `ops.slip_review.trans_ref` (per-tenant UQ today); `pm_schedule` → extend `ops.maintenance_plan`; "device protocol v2" → 1.3 additive on existing topics; `core.own_unit_ids()` does not exist; `title_deed_no` exists; `core.tenant_legal_form` already exists (new enum must be `core.building_legal_form`); internal transfer event must not be called `unit.transferred` (inbound integration type). Corrected in `J-juristic-api.md` (PROGRESS 2026-11-05).
5. **D-270 has no code and the dunning model is per invoice**: the collections ladder (per party × unit case, pausable, legal-form templates) is a new aggregate on the workflow engine, not an extension of `ops.dunning_reminder`; D-270's workspace starts from zero.
