## 3. Code
- `contract-kinds.ts` (kinds, signer roles, input variables per kind, sample data → variable catalogue),
  `contract-library-templates.ts` (drafts), `contract-diff.ts` (clause = `<section>` keyed by its `<h2>`),
  `contract-text-check.ts` (HTML whitelist — no script/style/handlers/links, no `{{{`/partials/unknown helpers;
  unknown variables; forbidden clause types: protective wording of the base removed + forbidden wording added,
  negation-aware, legal reference per ข้อ 5 (n) ⚖; block in scope / warn outside).
- `ContractLibraryService`: library list, template detail, copy (`derivedFromVersionId`), edit draft (new draft
  version when the latest is published), diff, check, publish (422 `compliance.forbidden_clause` in scope,
  `contract.unknown_variable`, `contract.template_invalid`), preview (sample data, disclaimer); admin list + legal
  review state.
- `ContractsService`: create (addendum on a lease, reservation on a unit for a party, co_broke on an agreement,
  brokerage_mandate on a mandate; auto-filled variables; unknown input variables refused), preview, send for
  signature (number, PDF, hash, legal hold), operator sign (drawn PNG, Idempotency-Key), resident / prospect sign
  (OTP + LINE + sha256), finalize (signed PDF as new version), cancel, download; a signed `co_broke` contract signs
  its proposed agreement (G2 in-app sign stays as fallback); mandates keep their accept flow, the contract is linked.
- `LeaseRenewalsService`: suggestion (k ≥ 5 benchmark `rent_per_m2` × area when the tenant opted in → comparables of
  the unit's listing → current rent), offer (issues the B7.5 `renewal_offer` letter in the same transaction),
  withdraw, resident accept (new renewal draft via `renew`, sent for signature) / decline (lessee notice to the end
  date when ≥ 30 days remain → D-219 move-out; otherwise the lease simply ends), job `lease-renewals` (expire past
  `respond_by`, owner reminders at `lease.renewal.remind_days`, skipping the B7.11 landlord reminder already sent).
- `LeasesService`: lease drafts may pin a tenant's own published lease template (`templateVersionId`); the hourly
  sweep closes a lease that reached its end when its renewal is already active (no move-out, deposit carried).
- `LeaseNoticesService`: a tenant's own published `notice_renewal` / `notice_termination` text replaces the built-in
  letter body for renewal offers / termination + non-renewal (B7.5 flow, numbering and PDF unchanged).
- Endpoints (owner `lease.read` / `lease.manage`, admin `admin.compliance.manage`): `GET /v1/owner/contract-library`,
  `POST /v1/owner/contract-templates`, `GET|PATCH /v1/owner/contract-templates/{id}`, `GET …/{id}/diff`,
  `GET …/{id}/preview`, `POST …/{id}/actions/check|publish`, `GET|POST /v1/owner/contracts`,
  `GET /v1/owner/contracts/{id}`, `GET …/{id}/preview`, `GET …/{id}/document`,
  `POST …/{id}/actions/send-for-signature|sign|cancel`, `GET /v1/owner/leases/{id}/renewal-suggestion`,
  `GET|POST /v1/owner/leases/{id}/renewal-offers`, `GET /v1/owner/renewal-offers`,
  `POST /v1/owner/renewal-offers/{id}/actions/withdraw`, `GET /v1/{resident|prospect}/contracts[/{id}]`,
  `GET …/{id}/document`, `POST …/{id}/signature/otp`, `POST …/{id}/sign`, `GET /v1/resident/renewal-offers[/{id}]`,
  `POST …/{id}/actions/accept|decline`, `GET /v1/admin/contract-library`,
  `PUT /v1/admin/contract-library/versions/{versionId}/legal-review`.
- Notifications: `contract.signature_requested` (resident LINE), owner events `lease.renewal_due`,
  `lease.renewal_accepted`, `lease.renewal_declined`.
